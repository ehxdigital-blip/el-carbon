# El Carbón PWA V1

## Publicar en GitHub Pages
1. Crea un repositorio nuevo (por ejemplo `el-carbon`).
2. Sube **el contenido de esta carpeta** a la raíz del repositorio.
3. En GitHub: Settings → Pages → Build and deployment → Deploy from a branch.
4. Selecciona `main` y `/ (root)` y guarda.
5. Abre la URL publicada en Safari en el iPhone.
6. Safari → Compartir → Añadir a pantalla de inicio.
7. Abre la app una vez con internet. Después prueba modo avión.

## V1
- 406 animales individualizados.
- Peso de venta editable.
- Ganancia mensual editable.
- Peso de compra editable.
- Capacidad de camión editable (14 por defecto).
- Números de animales por ventana de venta.
- Camiones proyectados.
- Reposición simulada 1 a 1.
- Ajustes guardados en el dispositivo.
- Funciona offline después de la primera carga.

Nota: esta V1 no registra ventas reales ni sincroniza datos entre dispositivos.
